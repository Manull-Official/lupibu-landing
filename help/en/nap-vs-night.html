How Lupibu tells a nap from night sleep

2 min read

In short: Automatically, by time: a sleep that starts in night hours or mostly overlaps the night counts as night sleep. There's no manual switch — if the type is wrong, adjust the entry's times and it reclassifies.

Nap vs night matters for predictions — night resets tiredness, naps don't.

How classification works

The type is set automatically, by two rules:

  • Start time. A sleep that starts in night hours (in the evening after the usual bedtime, or before morning) counts as night.
  • Night overlap. A finished sleep whose duration overlaps the night window by 60% or more also counts as night.

Everything else is a nap.

If the type came out wrong

There's no nap/night toggle in the entry — the type depends only on the times. Open the entry and fix the start or end time: classification recalculates automatically.

What it affects

  • Next-sleep prediction
  • Weekly stats (naps and night separately)
  • Wake-window calculation after sleep
